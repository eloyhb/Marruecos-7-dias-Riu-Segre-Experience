# Ruta Marruecos · GitHub Pages

Web estática y sin dependencias. Incluye:

- `index.html`
- `assets/hero-habibis.jpg`
- `assets/mapa-inspiracion.jpg`
- `.nojekyll`

## Publicarla gratis

1. Crea un repositorio público en GitHub, por ejemplo `ruta-marruecos`.
2. Sube **el contenido de esta carpeta** a la raíz del repositorio. `index.html` debe quedar arriba, no dentro de otra carpeta.
3. Abre **Settings → Pages**.
4. En **Build and deployment**, elige **Deploy from a branch**.
5. Selecciona `main` y `/ (root)`, y pulsa **Save**.
6. GitHub mostrará el enlace público en esa misma pantalla.

La dirección será parecida a:

`https://TU-USUARIO.github.io/ruta-marruecos/`

## Importante sobre la fotografía

La fotografía de cabecera contiene personas. Al publicar el repositorio y GitHub Pages, la imagen será accesible públicamente y podrá ser descargada por terceros. Comprueba que todos están de acuerdo antes de publicarla.

## Editar

Puedes modificar textos, tiempos y enlaces abriendo `index.html` con cualquier editor. No requiere instalación ni compilación.
